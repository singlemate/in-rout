# Инструкция по подключению к VPN

Статическая страница для Incy и v2RayTun. Сборка и зависимости не нужны: `index.html`, `styles.css`, `app.js` и папка `assets` публикуются вместе, в том числе через GitHub Pages.

## Сценарии

- Приложение установлено → выбор клиента → пошаговая настройка.
- Не установлено → выбор клиента → устройство → скачивание → подтверждение установки → настройка.
- Не удалось установить → помощь и возможность выбрать другой клиент.
- v2RayTun на iOS → пояснение про российский App Store, переход к Incy или настройке уже установленного v2RayTun.

Состояние находится в URL после `#`: работают обновление страницы, история браузера и прямые ссылки. Персональные VPN-ссылки не вводятся на сайте, не сохраняются и не отправляются на сервер.

Прямые ссылки на инструкции: `#setup/incy/1` и `#setup/v2raytun/1`.

## Ссылки и актуальность

Статус доступности указан на **27.09.2026**. Ограничение v2RayTun относится к **российскому App Store**, не ко всем регионам iOS.

- Incy: [официальный репозиторий и ссылки](https://github.com/INCY-DEV/incy-platforms), [App Store](https://apps.apple.com/ru/app/incy/id6756943388), [Google Play](https://play.google.com/store/apps/details?id=llc.itdev.incy).
- Имена установщиков Incy сверены с API последнего GitHub-релиза; ссылки используют `releases/latest/download`. Настольные сборки обозначены разработчиком как pre-alpha.
- v2RayTun: [репозиторий разработчика](https://github.com/LXST-CODE/v2RayTun), [Google Play](https://play.google.com/store/apps/details?id=com.v2raytun.android), [релизы Android](https://github.com/LXST-CODE/v2RayTun/releases?q=android). Резервная ссылка на универсальный APK закреплена на версии **5.25.82**; обновлять её в `app.js` при смене версии.
- Логотип Incy и его скриншоты сохранены из исходного репозитория. Логотип v2RayTun взят из его карточки Google Play и сохранён локально.

Профиль GrimbirdVPN Whitelist и ссылка импорта Incy сохранены из исходной инструкции. В v2RayTun добавлены установка баз Grimbird, импорт адаптированного профиля и выбор активного профиля перед подключением. Два скриншота iPhone предоставлены владельцем страницы: пустой список с кнопкой добавления и выбранный сервер до включения VPN.

### Маршрутизация v2RayTun

- Источник правил: [Grimbird INCY/WHITELIST.JSON, снимок 302cf69](https://github.com/GrimbirdUsers/ru-routing-dat/blob/302cf69/INCY/WHITELIST.JSON).
- `routing/grimbird-whitelist.json` — адаптация **правил маршрутизации**, а не готовый профиль от автора Grimbird для v2RayTun. DirectSites и DirectIp перенесены без изменения; DomainStrategy сохранён. DNS, DnsHosts и другие настройки Incy не входят в эту адаптацию.
- Отдельные правила для доменов и IP необходимы: объединение этих условий в одном правиле означало бы AND. Завершающее правило `ip: [0.0.0.0/0, ::/0]` отправляет прочие IP через proxy; network catch-all не используется, чтобы не обойти разрешение IP при IPIfNonMatch.
- Требуются пользовательские базы Grimbird GeoSite и GeoIP. Все используемые категории проверены в `.dat` исходного снимка. Эти базы не устанавливаются автоматически ссылкой импорта; на странице есть отдельный обязательный шаг. Если версия клиента не позволяет заменить базы, предлагается Incy.
- Схема `v2raytun://import_route/<base64url>` сверена с [исходниками генератора маршрутов](https://github.com/devemio/v2raytun-routing/blob/main/main.go); поля профиля — с [примером документации v2RayTun](https://docs.v2raytun.com/overview/supported-headers). Это не `import/` для серверов и не `incy://autorouting/`.
- Ссылка содержит JSON внутри себя, не зависит от публикации JSON на GitHub и сохранена в `routing/grimbird-whitelist-link.txt`. При публикации необходимо включить всю папку `routing`, включая JS-файл с профилем.
- Повторная сборка: `python build-routing.py PATH_TO_RU_ROUTING_DAT`. Скрипт проверяет наличие категорий в GeoSite/GeoIP и останавливается при несоответствии. Обновление внешних баз не обновляет состав правил в JSON; при смене исходного профиля нужна повторная сборка.
- **Ограничение проверки:** ссылка декодирована и проверена структурно, но импорт и активация не проверялись на реальном iOS/Android с v2RayTun. Названия и доступность меню зависят от версии. Перед публикацией требуется проверка на устройстве. Маршрутизация из подписки может иметь приоритет над локальным профилем (согласно документации клиента).

## Проверка

В headless Edge проверены обе ветки настройки, все пять платформ Incy, установка v2RayTun на Android, переход с iOS на Incy, помощь при установке, возврат назад, перезагрузка и неизвестный маршрут. Проверены загрузка изображений и отсутствие горизонтального переполнения при ширине 360, 390, 768 и 1280 px. Подключение к реальному VPN и установка приложений в эту проверку не входят.

Для локального просмотра можно открыть `index.html` или запустить любой статический HTTP-сервер из этой папки.
